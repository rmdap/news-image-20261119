(https://make.fun/bounty/news-image-20261119).

A front-page-style image summarising the day's world news: the first-ever
Trump–Xi–Putin trilateral summit in Shenzhen leads the page, followed by
Israel's ground operation beyond Gaza's Yellow Line, the third attack on the
Crimean Bridge this week, Anthropic's record $81.3bn IPO, the world court's
historic Rohingya verdict, the GTA VI global rollout, the record $190.4m
Van Gogh sale, Cyclone Akvan bearing down on India's east coast, Voyager 1
reaching one light-day from Earth, and McDonald's UK workers winning their
tribunal hearing. All events happened or were first reported on Thursday,
19 November 2026.

## How to run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png` (1024×1024, ~153 KB). Python 3.13, standard
library only — the program simply copies the bundled `entry.png`.
